## Project Overview

Collectible Books & Comics Store is a proposed e-commerce
website designed to sell rare books, collectible comics,
and limited-edition publications.

The project focuses on developing a structured website
plan, creating an accessible homepage prototype, and
documenting the future development of an online store.

The initial prototype demonstrates basic HTML structure,
CSS styling, featured products, and navigation links.

## Business Model

The website will operate as a business-to-consumer
(B2C) online retail store.

Customers will be able to browse collectible books
and comics, review product details, add products to
a shopping cart, and complete purchases through a
secure checkout system when those features are
implemented.

### Products Offered

- Rare and collectible books
- Science fiction books
- Fantasy books
- Mystery comics
- Limited-edition publications
- Collectible comic series

## Target Audience

The website targets:

- Book collectors
- Comic book enthusiasts
- Students
- Readers interested in rare publications
- Fans of science fiction, fantasy, and mystery

## Planned Website Pages

The completed website is planned to contain seven pages.

| Page | Planned File | Description |
|---|---|---|
| Store Homepage | index.html | Introduces the store and featured products |
| Product Catalog | products.html | Displays available books and comics |
| Product Details | product-details.html | Shows individual product information |
| Shopping Cart | cart.html | Allows customers to review selected products |
| Checkout | checkout.html | Provides secure order and payment processing |
| About Us | about.html | Describes the business and its mission |
| Contact | contact.html | Provides customer support information |

### Website Navigation Flow

Customers will begin on the Store Homepage and
navigate to the Product Catalog.

From the catalog, customers will select a product
to view its description, price, availability,
and other relevant information.

Customers will then add selected products to the
Shopping Cart, review quantities and totals,
and proceed to Checkout to complete their purchases.

The About Us and Contact pages will be accessible
through the main navigation menu.

The current homepage prototype uses internal
navigation links to demonstrate these planned
website sections.

## Brand Theme and Accessibility

The website uses a professional blue-and-white
color scheme to establish a clean, trustworthy,
and readable shopping experience.

### Selected Color Palette

| Color | Hex Code | Intended Use |
|---|---|---|
| Dark Blue | #24466B | Header, footer, and headings |
| Light Background | #F2F5FA | Main page background |
| Dark Text | #243247 | Primary body text |
| White | #FFFFFF | Content sections and header text |
| Gold Accent | #B67B13 | Product card borders |

### Accessibility Considerations

The website design includes:

- Semantic HTML elements
- Descriptive section headings
- Accessible navigation labels
- Keyboard-visible focus indicators
- Readable font sizes
- Clear navigation links
- Responsive layout planning
- Color contrast evaluation using WebAIM

The project proposal will include a WebAIM
Contrast Checker screenshot documenting the
selected text and background color contrast.
