# Collectible Books & Comics Store — SDC260 Assignment 2.6

Continuation of Assignment 1.9 Blueprints to Browsers. This educational static prototype includes seven semantic HTML pages and one shared external CSS stylesheet, with mobile-first CSS Grid and 768px/1024px media queries.

## Implemented this milestone
- Seven interconnected pages and consistent navigation
- Three sample catalog products and dedicated product-detail sections
- Shared navy/gold brand styling and accessible keyboard focus
- Mobile/tablet/desktop layouts
- Explicit placeholders for cart, checkout, and contact (not functional)

## Future roadmap
- Real product images and expanded inventory
- Working cart and order totals
- Contact form with validation and backend
- Secure hosted payment processing (no card storage on this static site)

Open `index.html` in a browser. All files should stay in the same directory.
